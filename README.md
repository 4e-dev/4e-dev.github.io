# Personal website
Personal portfolio + technical blog built with Hugo.
Hugo Theme: *hugo-xmin* by Yihui Xie

## Quick Commands

Run local development server:

```bash
hugo server
```

Build static site:

```bash
hugo
```

Build and include drafts:

```bash
hugo server -D
```

Generated site output:

```bash
public/
```

## Filesystem Overview

```txt
.
├── archetypes/            # Default templates for new content
│   └── default.md

├── assets/                # Processed assets (SCSS, JS, images)
│                           # Used by Hugo Pipes

├── content/               # Main website content
│   ├── posts/             # Blog posts
│   ├── projects/          # Portfolio/project pages
│   ├── about/             # About page
│   └── _index.md          # Homepage content

├── data/                  # YAML/JSON/TOML data files
│                           # Useful for structured content

├── i18n/                  # Multi-language translations
│                           # Ignore unless supporting localization

├── layouts/               # HTML layout overrides
│                           # Used to customize theme templates
│
│   Typical structure:
│   ├── _default/
│   ├── partials/
│   ├── posts/
│   └── projects/

├── public/                # Generated static site (BUILD OUTPUT)
│                           # Auto-generated by Hugo
│                           # Usually should NOT be edited manually

├── static/                # Static files copied directly to output
│                           # Good for:
│                           # - images
│                           # - resume PDF
│                           # - favicon
│                           # - downloadable assets

├── themes/                # Hugo theme source code
│                           # Avoid editing directly if possible

├── .hugo_build.lock       # Hugo lock file

└── hugo.toml              # Main site configuration
```

## Where Stuff Goes

### New Blog Post

Create:

```txt
content/posts/
```

Example:

```txt
content/posts/dx12-week-1.md
```

---

### Images For Blog Posts

Place in:

```txt
static/images/
```

Access in markdown:

```md
![DX12 Screenshot](/images/dx12-swapchain.png)
```

---

### Modify Website Layout / HTML

Edit:

```txt
layouts/
```

This overrides theme behavior.

Examples:
- Homepage layout
- Blog post formatting
- Navbar/footer
- Custom components

---

### Site Configuration

Edit:

```txt
hugo.toml
```

Used for:
- site title
- menus
- theme
- social links
- base URL
- params

---

### Theme Styling

Usually lives inside:

```txt
themes/
```

Try to override in:

```txt
layouts/
```

instead of modifying theme files directly.

This makes updates easier.

## Deployment Flow

1. Make changes
2. Test locally

```bash
hugo server -D
```

3. Commit changes

```bash
git add .
git commit -m "Update blog post"
git push
```

4. GitHub Pages / deployment updates automatically

---

## Notes To Future Me

- `public/` is generated — don't manually edit it.
- `content/` = actual writing/content.
- `layouts/` = HTML customization.
- `static/` = files copied directly.
- `themes/` = theme internals.
- If something looks visually broken, check `layouts/` first.
