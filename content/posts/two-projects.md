# A 2D game in godot
I officially started this project a few days ago. It started off as something that I felt
I had to build before going to the [new york games week](https://nygamesweek.com/), but 
have ultimately decided to take my time with.

The game's identity is strongly tied to *The Binding of Isaac.* Funnily enough, I am horrible
at dungeon crawler type games. It's probably because I'm terribly impatient. But the 
gameplay loop of looking for stuff and killing enemies *seems* simple enough. Before this game,
I had followed a tutorial to build a 2d metroidvania-like, so this will be my first attempt
at building something brand new.

# Opengl renderer (2.0!)
In lieu to building the game, I am also building (another) opengl renderer! My first
opengl renderer was built off of [LearnOpenGL](https://learnopengl.com/), which I'll
also use to help guide me again for my second renderer. This time, I want to add a bunch
more features, including a proper UI for inserting 3D models, audio, and eventually
cool stuff like animation.
